# Opportunity Detector Import Integration

This repository now treats `imports/opportunity-detector` as audited source
material rather than a second active product.

## Integration Contract

- `schemas/opportunity_import_flow.schema.json` defines the import plan shape.
- `examples/import_integration/opportunity_seed.json` is the golden input.
- `examples/import_integration/closed_loop_plan.golden.json` is generated by the
  deterministic adapter.
- `ode/imports/detector_integration.py` is the minimal task executor: read import
  assets, map them onto the ODE seven-stage flow, and validate the result.

## Closed Loop

1. Capture a seed opportunity with signals and constraints.
2. Convert it into a seven-stage ODE plan.
3. Check gates at `SCREEN`, `VALIDATE`, and `PLAN`.
4. Produce explicit artifacts and verification commands.
5. Run the same checks on Windows, macOS, and Linux CI.

## Commands

```bash
python tools/check_environment.py
python tools/validate_import_integration.py
python -m pytest
```

Update the golden plan after intentional integration changes:

```bash
python tools/validate_import_integration.py --write
```
